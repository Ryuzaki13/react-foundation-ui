## Практические рекомендации

- `onReadingChange` сообщает о чтении всей группы. До `false` форма должна блокировать отправку; новый выбор отменяет предыдущую группу без промежуточного `false`.
- Удаление выбранного файла, блокировка поля, смена режима и размонтирование отменяют незавершённое чтение. Устаревшие результаты и ошибки не вызывают callbacks.
- При ошибке отдельного файла `onReadError` сообщает отказ; успешно прочитанные файлы добавляются к прежнему выбору. `disabled` блокирует также удаление элементов списка.
- Если состояние должно жить во внешней форме или модели, ориентируйтесь на контролируемый режим из документации.
- При редактировании сущностей проверьте сценарий инициализации компонента уже существующими данными.
