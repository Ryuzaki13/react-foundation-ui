<Subtitle>Зона drag-and-drop для загрузки файлов кликом или перетаскиванием</Subtitle>

Компонент читает выбранную группу файлов и передаёт результат в `onChange`.
По умолчанию новый выбор заменяет прежний список; `append` сохраняет прежние файлы и добавляет успешно прочитанные.

## Основной сценарий

<Primary />

<Controls of={DropZoneStories.Basic} />

```tsx
import { useState } from "react";

import { type ReadFileResult } from "@ryuzaki13/react-foundation-lib/file";
import { DropZone } from "@ryuzaki13/react-foundation-ui/drop-zone";

export function Example() {
	const [files, setFiles] = useState<ReadFileResult[]>([]);

	return <DropZone append label="Материалы" value={files} onChange={setFiles} />;
}
```

## Практические рекомендации

- `label`, `description` и `error` оформляют поле и связывают подсказки с зоной выбора.
- `onReadingChange(true)` приходит перед чтением, `false` — после завершения или отмены. На это время можно заблокировать отправку формы.
- Новый выбор, удаление файла, `disabled` и размонтирование отменяют прежнее чтение. Запоздалый результат не меняет список.
- `disabled` запрещает и выбор, и удаление файлов. `multiple={false}` ограничивает одну новую группу первым файлом.
- `onChangeError` сообщает об ошибке отдельного файла; успешные файлы той же группы сохраняются. `onClearError` позволяет убрать прежнюю ошибку при новом выборе.
