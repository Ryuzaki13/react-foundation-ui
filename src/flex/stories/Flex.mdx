## SSR и responsive-пропсы

`Flex` формирует одинаковый markup на сервере и во время первого клиентского render. Для responsive map в DOM сразу присутствуют классы всех режимов, а активное значение выбирают media mixins из `styles/mixins/_media.scss`. Компонент не читает ширину окна и не ждёт hydration.

```tsx
<Flex.Container
	row={{ mobile: false, tablet: true }}
	column={{ mobile: true, tablet: false }}
	gap={{ mobile: "sm", tablet: "md", laptop: "xl" }}>
	<Flex.Item>Содержимое</Flex.Item>
</Flex.Container>
```

Значение, отсутствующее у текущего режима, наследуется по действующим правилам `ResponsiveValue`. Например, в исходном сценарии `column={{ mobile: true, tablet: false }}` значение `false` применяется и для `laptop`.
