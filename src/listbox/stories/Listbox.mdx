## Основной сценарий

```tsx
import { useState } from "react";

import { Listbox } from "@ryuzaki13/react-foundation-ui/listbox";

const options = [
	{ value: "draft", label: "Черновик" },
	{ value: "active", label: "В работе" },
	{ value: "done", label: "Завершен" }
];

export function Example() {
	const [value, setValue] = useState(undefined);

	return (
		<Listbox
			label="Статус"
			description="Выберите текущий статус задачи."
			size="md"
			options={options}
			value={value}
			onChange={setValue}
		/>
	);
}
```

## Практические рекомендации

- Начните с базового сценария ниже, а затем проверьте в stories те состояния, которые реально используются в вашем экране.
- Для ширины используйте общий prop `size`: `xs`, `sm`, `md`, `lg` или `xl`. Без `size` компонент занимает доступную ширину контейнера.
- Фокус остаётся на `listbox`: стрелки, `Home` и `End` перемещают активную опцию, а `Enter` или `Space` выбирают её. Содержимое `renderItem` должно быть неинтерактивным.
