## Основной сценарий

Modal root привязан к visual viewport, а не только к layout viewport: при открытии
экранной клавиатуры учитываются доступная высота и смещение видимой области.
`ModalManagerProvider` использует общий foundation-lib document lock; вложенный
Dialog не разблокирует документ родителя. Закрытие последней панели, включая
unmount provider, возвращает прежние inline styles и scroll X/Y.

Существующая inert-граница остаётся `#app-root`: consumer должен предоставить
этот контейнер для фонового приложения, оставив portal roots снаружи. Наличие
scroll lock само по себе не делает фон недоступным для assistive technology.
Проверяйте клавиатуру на физическом устройстве — изменение viewport Storybook
не воспроизводит iOS keyboard pan.

```tsx
import { useState } from "react";

import { Button } from "@ryuzaki13/react-foundation-ui";
import { Modal, ModalContent, ModalFooter } from "@ryuzaki13/react-foundation-ui";

export function Example() {
	const [open, setOpen] = useState(false);

	return (
		<>
			<Button onClick={() => setOpen(true)}>Открыть</Button>
			<Modal isOpen={open} title="Редактирование" onClose={() => setOpen(false)}>
				<ModalContent>Содержимое модального окна</ModalContent>
				<ModalFooter>
					<Button onClick={() => setOpen(false)}>Закрыть</Button>
				</ModalFooter>
			</Modal>
		</>
	);
}
```

## Практические рекомендации

- Если состояние должно жить во внешней форме или модели, ориентируйтесь на контролируемый режим из документации.
- Проверьте размер компонента в реальном контексте интерфейса: в таблицах, тулбарах и формах требования обычно отличаются.

## Цветовые роли

Основная поверхность окна использует `--bg-elevated`. Шапка, `ModalToolbar` и
`ModalFooter` отделяют служебные области фоном `--bg-secondary`. `ModalContent`
остаётся прозрачным и показывает основную поверхность окна. Заголовок сохраняет
`--text-primary`, а вложенные поля и кнопки — собственные цвета и состояния.

Настройка `--bg-secondary` в карте `tokens` mixin `theme($mode, $overrides: ())`
не меняет фон содержимого и не создаёт дополнительный уровень возвышения.
