# AnalyticalTable

`@ryuzaki13/react-foundation-ui/analytical-table` — аналитическая таблица полного снимка данных. Новый entrypoint требует `@ryuzaki13/react-foundation-lib >= 2.21.0 < 3`; старые UI entrypoints сохраняют прежние требования. Нужны peer-зависимости React, TanStack Virtual, DnD Kit, Floating UI и Lucide. Стили подключаются публичным `@ryuzaki13/react-foundation-ui/styles.css` вместе с темой проекта.

Таблица не загружает данные и не знает Query, OData, serverFn, маршруты и права. Host получает снимок через свой query/serverFn, передаёт неизменяемые `snapshot.rows` и стабильные `columns`. Агрегация, фильтрация и формулы выполняются один раз на изменение исходных данных или аналитического представления. Раскрытие дерева использует отдельную дешёвую проекцию, а ширина, порядок, закрепление и выделение не запускают расчёт модели.

## Данные и состояние

Каждая строка содержит `id`, необязательный `parentId`, `values` и необязательный `original`. Группировки добавляются над корнями исходного дерева. `column.grouping` разделяет ключи и отображаемые поля: одинаковые подписи с разными идентификаторами остаются отдельными группами. При `showAsColumn: false` поля группировки скрываются в колонках, подпись выводится в отдельной tree-ячейке. При `true` подпись выводится в колонке. Если поля подписи отсутствуют в UI descriptors, команда переноса в колонку недоступна; raw identity/display fields по-прежнему можно использовать для группировки. Вложенные `columnGroups` сохраняют несколько строк шапки и позволяют сворачивать подгруппы к `collapsedColumnId`.

`state` + `onStateChange` полностью управляют представлением; `defaultState` задаёт только начальное локальное состояние. Для новой области данных (например, новой даты) host меняет React `key`. При обычном обновлении snapshot устойчивые ID сохраняют раскрытие. Снимок не мутируется. Query timestamps и cache keys таблице не нужны.

`showGrandTotals`, `aggregation.isAggregateRow`, `aggregation.aggregate`, `aggregation.grandTotalsScope` определяют итоги. Стандартно учитываются корни исходного дерева; доменный host может выбрать другой набор. Для журналов с дочерними деталями это предотвращает двойной подсчёт. Формулы `formula` и `calculate`, генерация дат и подготовка динамических значений принадлежат foundation-lib/analytical-table. UI получает готовые descriptors и rows.

## Взаимодействия

- Заголовок сортирует колонку; Shift+клик добавляет её в множественную сортировку.
- Перетаскивание заголовка меняет порядок; resize handle меняет ширину, поддерживает клавиатуру и сброс двойным кликом.
- Меню заголовка доступно через кнопку, правую кнопку мыши и клавиатуру. Оно управляет группировкой, порядком уровней, закреплением и скрытием.
- Toolbar содержит доступ к скрытым колонкам, уровням группировки, активным фильтрам, сворачиванию, обновлению и экспорту. Обновление/экспорт появляются только при соответствующем callback.
- Выделение строк и ячеек независимо: `none`, `single`, `multi`; ячейки поддерживают `direct` и `primary-modifier`. `getRowCanSelect` ограничивает допустимые строки. Интерактивное содержимое сохраняет свои события. Строки используют публичный `useTableRowSelection`: исчезнувшие/недоступные строки удаляются из выбора с уведомлением host. Для ячеек сохраняется намерение выбора между фильтрами; активная проекция исключает отсутствующие координаты, а callback сообщает пользовательские команды. Копирование использует только активные ячейки и свежие значения текущего snapshot.
- Стрелки, Home и End перемещают фокус между ячейками. Переход за пределы текущего окна прокручивает Virtualizer и переносит фокус после появления DOM-ячейки. Enter/Space выбирает ячейку или строку согласно режимам, в tree-ячейке раскрывает ветку.
- Контекстное меню тела копирует форматированные значения, фильтрует по значению и управляет деревом. Один delegated menu и один ленивый overflow-popover обслуживают весь viewport.

`format` получает обычную строку, `formatTotal` получает только значение итога; `render` даёт React-содержимое исходных data rows, `renderGroup` — synthetic групп, `renderTotal` — итогов. Пустые dimension-ячейки групп свободны для подписи дерева; явный `renderGroup` ограничивает это пространство. Pipeline `formatting` сохраняет value/state/icon и правила по типу строки. `onExport` получает полный результат, включая строки вне viewport; host выбирает формат файла через foundation-lib/excel или другой транспорт. Тот же display formatter используется при копировании и экспорте; React renderer не преобразуется в текст автоматически.

## SSR и обновление

На import/render нет доступа к браузерным globals. `initialViewportHeight`, `rowHeight` и начальная геометрия шапки одинаковы на сервере и первом клиентском render. После mount Virtualizer и ResizeObserver уточняют размеры. Не меняйте initial props между SSR и hydration. При смене модели transient context menu/overflow закрываются. `error` отображает сбой обновления над последним снимком; auth-deny обрабатывает host, не передавая закрытые данные в таблицу.

Сценарии Storybook: `data-analyticaltable--hierarchy`, `--grouped`, `--grouping-as-column`, `--virtualized`, `--dynamic-dates`, `--empty`, `--refreshing`, `--failed-refresh`.
