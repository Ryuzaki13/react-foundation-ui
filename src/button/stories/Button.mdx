<Title>Button</Title>
<Subtitle>Базовая action-кнопка дизайн-системы для пользовательских действий, подтверждений и быстрых операций</Subtitle>

`Button` используется как универсальная кнопка интерфейса: в формах, тулбарах, модальных окнах, карточках, таблицах и компактных icon-only сценариях.

Ключевые особенности компонента:

- безопасный `type="button"` по умолчанию;
- явная настройка схемы через `tone + appearance`;
- поддержка иконки слева и справа;
- автоматический режим icon-only;
- всплывающая подсказка через `title`.

## Как выбирать схему оформления

Схема задаётся двумя независимыми свойствами: `tone` выбирает цветовой тон, а `appearance` — форму оформления.
Для акцентных и статусных действий можно выбрать `solid` с заливкой или `outline` с контуром.

Без обоих свойств кнопка использует нейтральный тон без отдельного `appearance`. Если задан только `tone`, применяется `outline`.
Если задан только `appearance`, используется нейтральный тон.

`neutral` не имеет отдельного варианта `solid`: `solid` и `outline` отображают одну нейтральную схему с рамкой. Для нейтрального действия выбирайте обычную кнопку с рамкой или `ghost`.

`ghost` всегда использует нейтральный тон, даже если передан другой `tone`.
Цветовые тоны `accent`, `error`, `warning`, `success` и `info` применяются к `solid` и `outline`.

### Каталог схем

<Canvas of={ButtonStories.Variants} />

Вторая группа в примере повторяет все варианты с `disabled`. Отключённое состояние не использует `opacity` и сохраняет структуру
`appearance`: у цветного `solid` нет видимой рамки, а у `ghost` не появляется фон.

```tsx
import { Button } from "@ryuzaki13/react-foundation-ui/button";

export function ActionVariants() {
	return (
		<>
			<Button tone="neutral" appearance="outline">
				Нейтральная
			</Button>
			<Button tone="neutral" appearance="ghost">
				Лёгкое действие
			</Button>
			<Button tone="accent" appearance="solid">
				Сохранить
			</Button>
			<Button tone="accent" appearance="outline">
				Предпросмотр
			</Button>
			<Button tone="success" appearance="solid">
				Подтвердить
			</Button>
			<Button tone="error" appearance="outline">
				Отменить
			</Button>
		</>
	);
}
```

## Иконки и компактные действия

Компонент поддерживает два сценария:

- кнопка с текстом и иконкой;
- кнопка только с иконкой.

Если в кнопке есть только `icon`, обязательно нужно передать `title` или `aria-label`, чтобы управление было доступным для скринридеров. В текущей реализации `title` также используется как содержимое всплывающей подсказки.

<Canvas of={ButtonStories.WithIcons} />

```tsx
import { BellIcon, CheckIcon, DownloadIcon, PlusIcon } from "lucide-react";

import { Button } from "@ryuzaki13/react-foundation-ui/button";

export function ButtonsWithIcons() {
	return (
		<>
			<Button icon={<DownloadIcon />}>Скачать</Button>
			<Button icon={<PlusIcon />} tone="info" appearance="solid">
				Создать
			</Button>
			<Button icon={<CheckIcon />} iconEnd tone="success" appearance="solid">
				Подтвердить
			</Button>
			<Button icon={<BellIcon />} title="Уведомления" />
		</>
	);
}
```

## Использование в формах

По умолчанию компонент рендерится как `type="button"`, поэтому он не отправляет форму случайно. Для submit-сценариев тип нужно указывать явно.

```tsx
import { Button } from "@ryuzaki13/react-foundation-ui/button";

export function FormActions() {
	return (
		<form onSubmit={handleSubmit}>
			<Button type="button" tone="neutral" appearance="ghost" onClick={handleReset}>
				Сбросить
			</Button>
			<Button type="submit" tone="success" appearance="solid">
				Сохранить
			</Button>
		</form>
	);
}
```

## Практические рекомендации

- Для явного оформления выбирай сочетание `tone` и `appearance`.
- Для акцентных и статусных действий выбирай `solid` или `outline`; нейтральные действия имеют рамку либо используют компактный `ghost`.
- Для операций удаления или других опасных действий используй `tone="error"` с `solid` или `outline`.
- Для иконки без текста всегда задавай `title` или `aria-label`.
- Если нужна кнопка удаления с подтверждением в два шага, стоит рассмотреть `ButtonRemove` из того же модуля.
- `disabled` блокирует нажатие, но не должен заменять явное объяснение пользователю, почему действие недоступно.
