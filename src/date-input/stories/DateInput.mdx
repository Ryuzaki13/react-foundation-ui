## Доступность

- Кнопка открытия календаря содержит `aria-haspopup="dialog"`, состояние `aria-expanded` и связь с панелью через `aria-controls`.
- Календарь объявляется немодальным диалогом с именем «Выбор даты» или «Выбор диапазона дат».
- Кнопки перехода называют единицу навигации, а текущий день помечается через `aria-current="date"`.
- Подпись, описание и ошибка текстового поля остаются связаны с самим полем через общую семантику `InputText`.

### Необязательная дата или период

`clearable` включает штатную кнопку очистки внутри поля рядом с календарём.
`SingleDateInput` и `RangeDateInput` сообщают очистку одинаково: `onChange(null)`.
Пустой ручной ввод тоже применяется по Enter или blur. Кнопка блокируется вместе
с полем, возвращает фокус к вводу и отменяет незавершённый календарный выбор.
Закрытие календаря после очистки не восстанавливает прежний период.

По умолчанию `clearable={false}`: существующие обязательные сценарии сохраняют
прежнее поведение. Поле само хранит незавершённый календарный выбор и выбранный
режим дня, недели, месяца или года; внешняя обёртка для этого не требуется.

### Ограничения по допустимым значениям

`minDate` и `maxDate` включительны и применяются к полному выбранному периоду,
включая ручной ввод. Для недели ограничение проверяет понедельник и последний
день, заданный `weekEndDay`; для диапазона проверяются оба заполненных конца.
Если текст выходит за границы, blur восстанавливает внешнее `value` без вызова
`onChange`. Значение не обрезается до ближайшей разрешённой даты. Без границ
прежнее поведение ввода и нормализации сохраняется.
