<Title>Badge</Title>
<Subtitle>Компактная текстовая метка для статусов, категорий, фильтров и коротких служебных пометок</Subtitle>

Badge подходит для коротких подписей, которые должны быстро читаться и не перегружать интерфейс:

- статусы и состояния записи;
- выбранные фильтры и теги;
- служебные пометки рядом с полями, карточками и строками таблиц;
- компактные списки значений с возможностью удаления.

Компонент принимает строку или число в `children`. Длинный текст автоматически ограничивается по ширине и сокращается через `TextOverflow`, поэтому Badge лучше использовать для коротких и однозначных формулировок.

## Основной сценарий

<Primary />

```tsx
import { Badge } from "@ryuzaki13/react-foundation-ui/badge";

export function Example() {
	return (
		<Badge tone="info" appearance="solid">
			Новый
		</Badge>
	);
}
```

## Визуальная схема

В компоненте есть два уровня настройки:

- `tone` задаёт семантику: `neutral`, `accent`, `success`, `warning`, `error`, `info`;
- `appearance` задаёт форму отображения: `solid`, `outline`, `ghost`.

`neutral` не имеет отдельного варианта `solid`: `solid` и `outline` отображают одну нейтральную схему с рамкой. Для нейтральной метки доступны обычное оформление с рамкой и `ghost`; заливка `solid` предназначена для акцентных и статусных тонов.

`ghost` сохраняет прозрачные фон и рамку, окрашивая содержимое по `tone`. Без `tone` и при `tone="neutral"` используется `text-secondary`, для акцента — `accent-text`, для статусов — `--<status>-text`.

Если схема не передана полностью, компонент достраивает её сам:

- без обоих свойств используется нейтральное оформление с рамкой без отдельного `appearance`;
- если задан только `tone`, применяется `outline`;
- если задан только `appearance`, используется нейтральный тон.

## Размеры

Badge поддерживает размеры от `xs` до `xl`. На практике чаще всего используются `sm` и `md`: они лучше всего подходят для строк таблиц, панелей фильтрации и карточек.

## Списки фильтров и выбранных значений

Для набора бейджей в одну строку или в несколько переносимых строк есть вспомогательный контейнер `BadgeList`. Это самый частый сценарий в проекте: выбранные фильтры, категории, теги и активные параметры поиска.

<Canvas of={BadgeStories.RemovableList} />

```tsx
import { useState } from "react";

import { Badge, BadgeList } from "@ryuzaki13/react-foundation-ui/badge";

export function SelectedFilters() {
	const [items, setItems] = useState(["Фильтр A", "Фильтр B", "Фильтр C"]);

	return (
		<BadgeList>
			{items.map((item) => (
				<Badge
					key={item}
					tone="info"
					appearance="outline"
					onRemove={() => setItems((prev) => prev.filter((value) => value !== item))}>
					{item}
				</Badge>
			))}
		</BadgeList>
	);
}
```

## Поведение и ограничения

- `children` должен быть строкой или числом, а не произвольным JSX.
- Без `onRemove` бейдж считается пассивным и не участвует во взаимодействии мышью.
- При передаче `onRemove` справа появляется встроенная кнопка удаления.
- Для длинных значений лучше использовать короткий видимый текст, потому что Badge рассчитан на компактные подписи, а не на развернутые описания.
- Схема оформления задаётся через `tone` и `appearance`; свойства `color` у компонента нет.
