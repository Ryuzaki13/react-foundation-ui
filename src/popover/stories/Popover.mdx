## Основной сценарий

<Primary />

```tsx
import { Button } from "@ryuzaki13/react-foundation-ui/button";
import { Popover } from "@ryuzaki13/react-foundation-ui/popover";

export function Example() {
	return (
		<Popover>
			<Popover.Trigger>
				<Button>Открыть</Button>
			</Popover.Trigger>
			<Popover.Content role="dialog" aria-label="Параметры отображения">
				<div style={{ padding: 12 }}>Содержимое поповера</div>
			</Popover.Content>
		</Popover>
	);
}
```

## Практические рекомендации

- Popover является немодальным: фон остаётся доступным, а фокус может перейти за пределы панели. Для блокирующего сценария используйте `Dialog` или `Modal`.
- Компонент не назначает `role` автоматически. Для самостоятельной интерактивной панели задайте подходящую семантику и доступное имя, например `role="dialog"` вместе с `aria-label` или `aria-labelledby`.
- `FloatingPopover` для короткой подсказки использует `role="tooltip"`, открывается и при наведении, и при фокусе, а trigger связывается с подсказкой через `aria-describedby`.
- Если состояние должно жить во внешней форме или модели, ориентируйтесь на контролируемый режим из документации.
- Если компонент участвует в фильтрации или поиске, заранее определите дефолтные значения и допустимые ограничения.
