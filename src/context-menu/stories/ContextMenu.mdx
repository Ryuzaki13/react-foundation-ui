```tsx
export function Example() {
	return (
		<DropdownMenu>
			<DropdownMenu.Trigger>
				<button type="button">Действия</button>
			</DropdownMenu.Trigger>
			<DropdownMenu.Content>
				<DropdownMenu.Item>Редактировать</DropdownMenu.Item>
				<DropdownMenu.Item>Удалить</DropdownMenu.Item>
			</DropdownMenu.Content>
		</DropdownMenu>
	);
}
```

## Практические рекомендации

- Начните с базового сценария ниже, а затем проверьте в stories те состояния, которые реально используются в вашем экране.
- `DropdownMenu` открывается с trigger-кнопки через `Enter`, `Space`, `ArrowDown` и `ArrowUp`.
- Обычный `ContextMenu.Trigger` автоматически становится доступным из tab-порядка; при делегировании через `resolveTrigger` клавиатурно доступными должны быть сами вложенные цели.
- Оба вида меню связывают popup с trigger через `aria-controls` и `aria-labelledby`. Для делегированных или составных областей задайте `aria-label` у `Content` явно.
- В открытом меню используйте стрелки, `Home`, `End`, поиск по первой букве, `Escape` и `Tab`.
